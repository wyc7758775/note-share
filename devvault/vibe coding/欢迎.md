# 欢迎使用 NoteShare

这是一个 **Obsidian 兼容**的笔记库：你现在看到的这个文件夹，可以直接用 Obsidian 打开当作它自己的库，两边编辑的是同一批 `.md` 文件。

## 这个笔记软件能做什么

- 像 Obsidian 一样按**文件夹**管理笔记（左侧边栏）
- 所见即所得地写作，文件始终保存为标准 Markdown
- 插入 **Excalidraw 手绘画板**（存为 `attachments/*.excalidraw`，Obsidian 的 Excalidraw 插件也能编辑）
- 单篇笔记一键**发布**：导出单文件 HTML，或推送到你自己的服务器生成分享链接

## 试试这些

1. 点左上角 **新笔记**，写点什么，它会自动保存（1 秒左右）
2. 在工具栏点 ✏ **画板按钮**，画一个流程图，点「完成并保存」
3. 点右上角 **发布 / 导出**，把这篇笔记导出成 HTML 发给朋友看

> 提示：`Ctrl + S` 立即保存；笔记标题就是文件名，改标题会自动重命名文件。
